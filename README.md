# Gestión de Productos

Aplicación web desarrollada con JavaScript para administrar un catálogo de productos. Permite agregar productos, visualizar sus datos en una tabla y eliminarlos. Los datos se guardan en el navegador mediante `localStorage`.

## Funcionalidades

- Agregar productos con código, nombre, precio y URL de imagen.
- Mostrar los productos en una tabla dinámica.
- Eliminar productos del catálogo.
- Evitar códigos de producto duplicados.
- Guardar y recuperar los productos mediante `localStorage`.
- Mostrar las imágenes de los productos.
- Interfaz sencilla y adaptable con Tailwind CSS.

## Tecnologías utilizadas

- HTML5
- JavaScript
- Tailwind CSS
- DOM
- localStorage
- Módulos de JavaScript

## Cómo ejecutar el proyecto

1. Cloná el repositorio:

   ```bash
   git clone https://github.com/Cecy-1984/gestion-productos.git
   ```

2. Entrá en la carpeta:

   ```bash
   cd gestion-productos
   ```

3. Abrí el proyecto con Visual Studio Code.

4. Ejecutá `index.html` usando Live Server.

También es posible abrir la página publicada mediante GitHub Pages cuando el despliegue esté disponible.
